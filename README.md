One word for my Wi-Fi: **Diva**.

Home Wi-Fi behaves like a temperamental star — flawless until the moment
it matters, then it storms off mid-call and refuses to perform until
conditions are exactly to its liking.

`main.py` (pure Python standard library, `os` only) writes exactly one
word — 4 characters — to `/output/entry.txt`.

## Why this word

> Diva

Home Wi-Fi behaves like a temperamental star: flawless until the moment it
matters, then it storms off mid-call. "Diva" is not in the standard Wi-Fi
complaint vocabulary (slow, dead, buffering, laggy), so it is a surprising
angle on a familiar annoyance — and funny as an actual network name.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same word, byte for byte, on every run.
